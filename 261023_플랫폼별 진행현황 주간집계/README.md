# 플랫폼별 진행현황 주간집계

## 개요
- 목적: 드라마본부 프로젝트의 플랫폼 협의 현황을 매주 플랫폼 > 프로젝트 > 진행사항으로 정리한다.
- 기준 파일: Google Sheets "드라마본부 회의" > `드라마본부 회의` 탭 M열(진행현황), https://docs.google.com/spreadsheets/d/1tcf0nfNu-ogI0GrOzKsvneu0SHbKPrH3szfTpWy8mlA/edit
- 대상 행: B열 No.가 숫자인 진행 중 프로젝트(구분① Drop 행 제외)
- 집계 기준: 실제 제안·검토·GLC·피드백·조건 협의 건만. 단순 목표 플랫폼, 과거 고사·불발·납품완료 건은 제외. 복수 플랫폼 협의 프로젝트는 플랫폼별로 한 줄씩 분리
- 보고 형식: 「플랫폼 제안 현황」 보드 — 구분(JTBC / 타채널 / 오리지널) > 플랫폼(카드 수) > 프로젝트 카드 "현재 상태 → 다음 단계". 결과 md를 사용자가 보드로 옮겨 보고한다
- 시트 작성 규칙: M열 업데이트 내용은 파랑 글씨(#1153CC 계열)로 적는다. 다만 지난 파랑이 남아 있을 수 있어 파랑은 참고만 하고, 변경 판단은 전주 결과·M열 스냅샷과 전체 내용을 비교해서 한다(사용자)
- 보드의 '후보작' 영역은 주간 집계에 넣지 않는다(사용자)
- 보드 카드는 전주 보드에 있던 것만 두고 구분도 그대로 따른다. 보드에 없는 플랫폼 협의는 '보드 밖 플랫폼 협의 건' 참고 섹션에만 적는다(2026-10-26 사용자)
- 마지막에 이번 주 의사결정·피드백 예정 3건 이내 별도 표시, 전주 대비 신규·변경·종료는 비교 가능할 때만 표시
- 정기 실행: 예약 작업 `drama-platform-weekly`, 매주 금요일 10:00 (첫 실행 2026-10-30). 결과는 `결과/YYMMDD 플랫폼별 진행현황.md`
