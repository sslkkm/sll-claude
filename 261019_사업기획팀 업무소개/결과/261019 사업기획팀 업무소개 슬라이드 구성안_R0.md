# 사업기획팀 업무소개 슬라이드 구성안 (R0)

신임 대표님 보고용 자료의 슬라이드 구성안이다. 디자인 작업 전에 흐름과 장별 내용을 먼저 확정하기 위한 문서다.

## 1. 기본 방향

- **포맷**: `240313_SLL_제작부문 업무보고_R6.pptx`(CEO 업무보고)의 틀을 그대로 쓴다. 가로 27.5×19.1cm 화면에 표지(빨간 대제목과 SLL 로고), 장 구분 간지(장 제목과 우측 소목차), 본문 슬라이드(좌상단 빨간 태그와 제목, ■ 핵심 메시지 한 줄, 하단 `n / N` 쪽번호)로 구성한다.
- **본문 레이아웃**: 첨부 문서에 이미 있는 네 가지 유형을 재사용한다.
  - (A) 조직도와 4열 박스 (업무보고 4p, 조직별 소개자료 1p)
  - (B) 구성원별 담당업무 박스 (조직별 소개자료 2p)
  - (C) 단계×조직 역할 매트릭스 표 (업무보고 6p)
  - (D) 3단계 화살표와 목적·내용·주관 행, 하단 제작과정 타임라인 (업무보고 8~10p)
  - (E) 중점추진 표: 전략·내용·해당업무 (25년 부서업무현황표)
- **보고 관점**: 대표님이 처음 보는 자료이므로 "이 팀이 회사에서 어떤 의사결정을 지원하는가"를 앞에 둔다. 업무 나열보다 제작 의사결정(GLC)과 손익관리에서 맡는 역할을 중심으로 정리한다.

## 3. 확정된 사실 / 제안 / 확인 필요

**자료로 확인된 사실**
- 제작기획팀 업무 4대 영역: 기획총괄, 프로젝트 수익관리, 프로젝트 계약관리, 업무 고도화 (25년 부서업무현황표, '24.9)
- 제작 6단계별 제작기획팀 역할: Key Resource 관리, 대본검토·제작유통회의, 사전 리쿱율·주요 계약, 월별 리쿱율 트래킹, 사후 리쿱율·제작비 DB (업무보고 6p, '24.3)
- 회사 방향: Multi-Platform & Multi-Content 전환, Original 중심 리소스 재배치, 스탭 부서 통합 (2026 내일컨퍼런스 자료)

**구성안에서 제안한 것**
- 15장 내외의 4장 구조, 슬라이드별 레이아웃 배정, 핵심 메시지 문구(案)

**확인이 필요한 것**
- 사업기획팀으로 명칭을 바꾼 시점·사유와 현재 소속 조직도
- 명칭 변경 후 추가되거나 이관된 업무 (예: 스탭 부서 통합에 따른 변화)
- 현재 구성원과 담당
- 회의체 현황 (QC위원회 운영 여부, 대본검토·제작유통회의 유지 여부)
- 성과로 넣을 수치 (관리 프로젝트 수, 계약 건수, 리쿱율 등)
- 보고 일자, 분량 제한, 조직 이슈·건의 슬라이드 포함 여부
