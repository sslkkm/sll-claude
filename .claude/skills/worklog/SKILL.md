# 업무일지 작성

1. 오늘 날짜를 확인한다.
2. 이 대화에서 작업한 업무 폴더(`YYMMDD_업무명`)를 찾는다. 여러 개면 각각 기록하고, 어느 폴더인지 애매하면 기록하기 전에 묻는다.
3. 그 폴더의 README.md를 먼저 읽는다.
4. `## 진행 기록` 맨 아래에 `- YYYY-MM-DD: 한 줄 요약`을 추가한다.
   - 한 일과 확인된 결과, 만들거나 고친 파일 경로(`결과/...`)를 적는다.
   - 제안만 한 일, 시도했지만 확인하지 못한 일은 완료로 적지 않는다.
   - 이 대화 밖에서 사용자가 한 일은 추측해서 적지 않는다.
   - 같은 날 같은 내용이 이미 있으면 중복해서 추가하지 않는다.
5. 상태가 바뀌었을 때만 상태 섹션을 고친다.
   - `## 현재 상태`의 마지막 확인일과 내용
   - `## 다음 행동`: 끝난 항목은 빼고, 새로 생긴 할 일을 넣는다
   - `## 아직 결정하지 않은 것`: 사용자 확인을 기다리는 것을 넣고, 결정된 것은 뺀다
   - 상태 섹션이 없는 예전 README면 진행 기록 위에 CLAUDE.md의 형식대로 만든다.
6. 기존 진행 기록은 지우거나 고쳐 쓰지 않는다.
7. 고친 파일 경로와 추가·변경한 내용을 짧게 보여준다.
