# 오늘 할 일 정리

파일은 수정하지 않는다. 읽고 정리만 한다.

1. 오늘 날짜를 확인한다.
2. 최상위의 `YYMMDD_업무명` 폴더마다 README.md를 읽는다. `## 현재 상태`가 `완료`인 업무는 목록 끝에 이름만 적는다.
3. 다음 순서로 정리한다.
   - **내 결정·확인이 필요한 것**: `## 아직 결정하지 않은 것`과 사용자 확인 대기 항목
   - **다음 행동**: 업무별로 묶어서. 날짜나 마감이 적혀 있으면 함께 적는다
   - **점검이 필요한 상태판**: 마지막 확인일이 7일 넘게 지났거나, 상태 섹션이 없거나, 다음 행동이 진행 기록과 맞지 않아 보이는 업무
4. 각 항목 끝에 출처 업무 폴더 이름을 붙인다.
5. README에 없는 일정이나 할 일은 만들지 않는다. 우선순위는 제안까지만 하고, 정하는 것은 사용자에게 맡긴다.
