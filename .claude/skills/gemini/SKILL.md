# Gemini 호출

회사 계정(kwon.kyungmin@sll.co.kr)의 Google AI Studio API 키로 Gemini를 부른다.

## 보내도 되는 자료

- 지금 키는 **무료 등급**이다. 무료 등급에서 보낸 내용은 구글 서비스 개선에 쓰일 수 있으므로 **회사 자료, 개인정보, 미공개 정보는 보내지 않는다.** 공개 정보 검색과 일반 질문에만 쓴다.
- 보낼 내용이 이 기준에 맞는지 애매하면 보내기 전에 사용자에게 확인한다.
- 유료 등급으로 바뀌면 이 섹션을 고친다.

## 사용법

```
python .claude/skills/gemini/gemini.py "질문"
python .claude/skills/gemini/gemini.py --search "최신 정보가 필요한 질문"
python .claude/skills/gemini/gemini.py --file 파일경로 "이 자료를 요약해줘"
python .claude/skills/gemini/gemini.py --list-models
```

- 기본 모델은 `gemini-flash-latest`(최신 Flash를 따라감)이다.
- `--search`: 구글 검색을 근거로 답하고 출처 목록을 함께 출력한다. 무료 등급에서는 검색 할당량이 `gemini-2.5-flash`에만 있어 이 모델로 자동 전환된다. 출처 링크는 구글 중계 주소라 원문 확인이 필요하면 해당 매체에서 다시 찾는다.
- `--file`: PDF, 이미지, 텍스트 파일을 첨부한다. 여러 번 쓸 수 있다.
- `--model`: 기본 모델 대신 다른 모델을 쓴다. 쓸 수 있는 이름은 `--list-models`로 확인한다.
- `--prompt-file`: 긴 작업 지시서를 파일에서 읽는다. 뒤에 질문을 함께 쓰면 지시서 아래에 덧붙는다.
- `--out`: 결과 전문을 파일로 저장하고, 화면에는 저장 경로, 분량, 토큰 수, 앞부분 미리보기(`--preview`, 기본 300자, 0이면 생략)만 출력한다. 응답이 잘리거나 차단되면 경고를 함께 낸다.
- `429` 오류는 무료 할당량 초과, `503`은 구글 쪽 일시 과부하다(503은 자동으로 두 번 더 시도한다).

## 작업 맡기기 (Claude 토큰 절약)

Claude가 읽는 양이 곧 토큰이므로, 원문 읽기와 긴 글 생성은 Gemini에 맡기고 Claude는 지시와 확인만 한다. 사용자가 요청하지 않아도 아래 맡기기 좋은 일에 해당하고 `보내도 되는 자료` 기준을 충족하면 맡긴다. 맡겼을 때는 Gemini에 맡겼다는 것과 Claude가 확인한 범위를 답에 밝힌다.

1. **지시서 작성**: 목적, 결과 형식(목차·분량·표 여부), 지켜야 할 조건, "자료에 없는 내용은 만들지 말고 `[확인 필요]`로 표시" 같은 규칙을 짧게 적는다. 길면 `--prompt-file`로 넘긴다.
2. **원문은 Claude가 열지 않는다**: 첨부 자료는 `--file` 경로로만 넘긴다.
3. **결과는 파일로 받는다**: 항상 `--out`을 쓴다. 업무 폴더가 있으면 그 폴더 `결과/`에 `YYMMDD 문서명_Gemini초안.md`처럼 저장하고, 일회성 질문이면 스크래치패드에 저장한다.
4. **확인은 필요한 만큼만**: 전문을 다 읽지 않고, 숫자·날짜·고유명사와 `[확인 필요]` 표시가 있는 줄을 검색해 원문과 대조한다. 형식이나 빠진 항목은 목차(제목 줄)만 뽑아 본다.
5. **고칠 때도 Gemini에게**: 수정 지시를 지시서에 추가해 다시 돌리고 `_R0`, `_R1`로 새 파일에 받는다. 작은 수정만 Claude가 직접 한다.

맡기기 좋은 일은 긴 자료 요약, 공개 정보 조사, 초안 작성, 표 정리처럼 결과를 부분 확인할 수 있는 일이다. 판단이나 맥락이 많이 필요한 일, 결과를 결국 전부 읽어야 하는 짧은 글은 Claude가 직접 하는 편이 낫다. 위 `보내도 되는 자료` 기준은 그대로 적용된다.

## 결과 다루기

- Gemini 답은 초안으로 취급한다. 숫자, 날짜, 고유명사는 출처나 원문과 대조한 뒤 쓴다.
- 사용자에게 전할 때는 Gemini가 낸 내용이라는 것과 확인한 범위를 밝힌다.
