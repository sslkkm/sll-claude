# 뉴스레터 중복기사 정리

## 개요

회사 Outlook(kwon.kyungmin@sll.co.kr) 받은 편지함\뉴스레터 폴더에 매일 쌓이는 뉴스레터를 읽어, 여러 뉴스레터가 겹쳐 다룬 기사·주제를 중요도가 높은 것으로 보고 순서대로 정리한다. 메일은 클래식 Outlook COM(PowerShell)으로 읽기만 한다.

- 추출 스크립트: `도구/extract_newsletters.ps1` (기간은 `도구/last_run.txt` 시각부터 실행 시점까지, 실행 후 자동 갱신)
- 메일 원문: `자료/YYMMDD 뉴스레터 원문.txt` / 브리핑: `결과/YYMMDD 뉴스레터 브리핑.html` (틀은 `도구/briefing_template.html`, 데이터 블록만 바꿈)
- 브리핑 링크(매일 같은 주소로 갱신): https://claude.ai/artifact/N4f3MYqi7chjxsTLLa2Bee (2026-11-10 Claude 계정 전환으로 새 주소. 이전 주소 DnDcYBssP9Y2HTWer8nriZ는 이전 계정 소유)
- 자동 실행: Claude 앱 예약 작업 `newsletter-daily-digest` (평일 09:00, 실패한 날만 11:00 재시도, Auto 모드)

## 현재 상태

마지막 확인일 2026-11-05 / 11/05 9시 실행에서 Outlook 연결·추출이 정상 동작해(09:16 완료) 10통을 정리하고 브리핑을 갱신했다. 새 대기 방식이 9시 실행에서도 통하는 것을 확인했다.
