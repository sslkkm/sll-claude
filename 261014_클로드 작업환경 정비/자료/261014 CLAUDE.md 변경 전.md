# SLL Claude 작업 폴더 규칙

## 폴더 구조

업무 단위마다 최상위에 작업 폴더를 하나씩 만든다. 최상위에는 작업 폴더와 이 파일 외에 다른 파일을 두지 않는다.

```
SLL Claude/
├─ CLAUDE.md
├─ YYMMDD\_업무명/
│  ├─ README.md   업무 개요, 요청사항, 진행 기록
│  ├─ 자료/        받은 원본·참고 자료 (수정하지 않음)
│  └─ 결과/        작성한 산출물
└─ ...
```

## 규칙

* 폴더명: `YYMMDD\_업무명` (업무 시작일 기준, 예: `261013\_SLL 프로젝트 담당실적`)
* 새 업무를 시작하면 먼저 작업 폴더와 README.md를 만들고, 이후 파일은 그 폴더 안에서만 생성·수정한다.
* 기존 업무의 후속 요청이면 새 폴더를 만들지 않고 해당 폴더에서 이어서 작업한다. 어느 업무인지 애매하면 사용자에게 확인한다.
* 산출물 파일명: `YYMMDD 문서명.확장자`, 수정본은 `\_R0`, `\_R1` … 을 붙인다. 이전 버전은 덮어쓰지 않는다.
* `자료/`의 원본 파일은 직접 수정하지 않고, 필요하면 복사해서 `결과/`에서 작업한다.
* 작업이 끝나면 README.md 진행 기록에 날짜와 한 줄 요약을 남긴다.
* \- 나는 여러 프로젝트를 함께 운영하는 기획자다.
* \- 한국어로 답하고, 업무 문서는 자연스러운 줄글을 기본으로 작성한다.
* \- 작업을 시작하기 전에 관련 자료를 읽고 목적과 현재 상황을 확인한다.
* \- 확정된 사실, 제안, 확인이 필요한 내용을 구분하고 없는 정보는 만들지 않는다.
* \- 대외 발송과 핵심 의사결정은 내가 한다. 필요한 초안과 선택지를 준비한다.
