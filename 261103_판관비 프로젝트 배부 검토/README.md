- 요청: 팀장님(2026-11-03, 프로젝트 손익 시뮬레이터 MVP의 다음 단계)
- 원천: 9월본 손익계산서 `6.판관비` 시트(복사하지 않고 참조: `261029_프로젝트 손익 검증모델/자료/★2026 SLL 손익계산서(9월 마감,10월 추정)_1019_사업기획팀송부.xlsx`), 프로젝트 매출은 프로젝트 손익 시뮬레이터(`261029_프로젝트 손익 검증모델/결과/261103 프로젝트 손익 시뮬레이터(9월본)_R13.html`) 기준
- 9월본 판관비: FY26 360.1억, FY27 265.7억(인건비 88.4/85.5, 감가·무형상각 57.2/58.3, 지급수수료 65.9/52.0, 광고선전 16.5/16.7, 복리후생 22.1/22.1, 대손상각 79.5/0.0, 그 밖 30.5/31.1). 매출원가 쪽 제작인건비 38.3억은 따로 있음(그중 31.2억 자산화)
- 원본에 인원 수·부서별 인원·1인당 인건비·채용 계획은 없음
